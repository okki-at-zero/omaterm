# Omadots (vendored)

Dotfiles and shell configuration shared by Omaterm, vendored from the archived
[`omacom/omadots`](https://github.com/omacom/omadots) repository (formerly
`omacom-io/omadots`).

The image build installs these configs via `install.sh` instead of fetching the
retired upstream repository, so the build does not depend on it staying online.
`install.sh` still clones [LazyVim](https://github.com/LazyVim/starter) from its
own upstream.
